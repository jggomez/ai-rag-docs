# Data Model: Ingest Received Document and Exclude Current Document in RAG Retrieval

This document outlines the domain entities and their persistence mappings in Firestore for the `005-update-retrieve-ingest-received` feature.

## 1. SourceDocument Entity Mapping

Documents are saved in two separate Firestore databases/collections depending on their `tipo_documento` (`RECEIVED` vs `SENT`).

### Collection: `documentos` (in `docs-recibidos` and `docs-enviados` databases)

| Firestore Field | Type | Entity Field | Description |
| :--- | :--- | :--- | :--- |
| `id` | String | `id` | Suffix-based unique ID: `{draft_id}_REC` or `{draft_id}_SEN` |
| `nombre_archivo` | String | `filename` | Name of the PDF file (e.g. `{code}.pdf`) |
| `nombre_objeto` | String | `object_name` | The storage object name / code identifier (without `.pdf` extension) |
| `tipo_contenido` | String | `content_type` | Always `application/pdf` |
| `tamano_bytes` | Integer | `size_bytes` | File size in bytes |
| `creado_en` | Timestamp | `created_at` | Ingestion timestamp |
| `estado` | String | `status` | `PENDIENTE`, `PROCESANDO`, `COMPLETADO`, `FALLIDO` |
| `tipo_documento` | String | `document_type` | `RECIBIDO` or `ENVIADO` |
| `url_origen` | String | `source_url` | Download link |
| `url_recibido` | String | `metadata["url_recibido"]` | Original received URL cross-reference |
| `url_enviado` | String | `metadata["url_enviado"]` | Response file URL cross-reference |
| `frente_trabajo` | String | `work_front` | Work front metadata (e.g., `Descarga intermedia`) |
| `fecha_documento` | String | `document_date` | Date of the document |
| `url_archivo_respuesta`| String | `response_file_url` | Response file URL |
| `id_borrador` | String | `draft_id` | Draft ID association |
| `texto_extraido` | String | `metadata["extracted_text"]` | Full text extracted |

## 2. DocumentChunk Entity Mapping

Chunks are generated by segmenting the document text and generating embeddings.

### Collection: `documentos_chunks` (in `docs-recibidos` and `docs-enviados` databases)

| Firestore Field | Type | Entity Field | Description |
| :--- | :--- | :--- | :--- |
| `id` | String | `id` | Firestore generated unique ID |
| `id_documento` | String | `document_id` | Reference to parent document's `id` |
| `asunto` | String | `subject` | Extracted document subject |
| `texto` | String | `text` | Formatted search context: `{asunto}\n{body}` |
| `url_origen` | String | `url_origen` | Copy of parent's `url_origen` |
| `url_recibido` | String | `url_recibido` | Copy of parent's `url_recibido` |
| `frente_trabajo` | String | `work_front` | Copy of parent's `frente_trabajo` |
| `fecha_documento` | String | `document_date` | Copy of parent's `fecha_documento` |
| `id_borrador` | String | `id_borrador` | Copy of parent's `id_borrador` |
| `nombre_archivo` | String | `nombre_archivo` | Copy of parent's `nombre_archivo` |
| `url_archivo_respuesta`| String| `url_archivo_respuesta` | Copy of parent's `url_archivo_respuesta` |
| `indice_chunk` | Integer | `metadata["chunk_index"]` | Sequential chunk index |
| `vector` | Vector (768) | `embedding` | Semantic vector generated via Gemini Embedding API |
